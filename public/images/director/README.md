# संचालकांचे फोटो / Director photographs

इथे दोन्ही संचालकांचे फोटो ठेवा:

- `director-1.jpg` — पहिले संचालक
- `director-2.jpg` — दुसरे संचालक

नंतर `src/content/landing.ts` मध्ये `DIRECTORS` मधल्या `photo` ला path द्या:

```ts
photo: '/images/director/director-1.jpg',
```

## फोटो कसा असावा

- **उभा (portrait) फोटो** — चौकट 4:5 आहे.
- किमान **800 × 1000 pixels**.
- गणवेशातला, परेड ग्राउंडवरचा किंवा service weapon सोबतचा फोटो चांगला दिसेल —
  चौकट उभी असल्याने पूर्ण उंचीचा फोटो व्यवस्थित बसतो.
- चेहरा वरच्या भागात असेल असा फोटो निवडा (crop वरून 20% धरलेला आहे).
