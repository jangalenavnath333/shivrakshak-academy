Shivrakshak Academy

ERP & Official Web Portal

A Complete Enterprise Resource Planning & High-Performance Web System for Defense Academies

Academic Year: 2025-2026

Introduction

  • What is Shivrakshak Academy? A premier defense academy in Maharashtra training youth for the Indian Army, Police, and SRPF.
  • The Core Idea: Transitioning from scattered manual operations to a centralized ERP (Enterprise Resource Planning) system.
  • Project Goal: To build an ultra-premium, cinematic landing page for brand awareness, fully integrated with a robust backend ERP for end-to-end academy management.

Problem Statement

  • No Centralized System: Data was scattered across physical files and excel sheets, making academy administration difficult.
  • Manual Admissions: Paper-based admission forms were slow, prone to data loss, and hard to track.
  • Offline Exams: Conducting mock tests manually required excessive printing, time, and manual evaluation.
  • Media Management: No direct system to dynamically update academy photos and videos for marketing.

Proposed ERP Solution & Objectives

  • Centralized ERP Dashboard: A secure, all-in-one Admin Portal to manage the entire academy's operations.
  • Premium Public Portal: A dynamic, cinematic website using 'Glassmorphism' UI to attract students.
  • Digital Admission System: Paperless data entry with instant printable admission receipts.
  • Online Exam Portal (CBT): A fully functional Computer Based Test engine for real-time exam practice and instant scoring.

Technology Stack

Frontend Framework: Next.js 14 (App Router) & React 18

Styling: Vanilla CSS3 with Custom Glassmorphism variables

Backend/API: Next.js Server Actions & API Routes

Database: Supabase (PostgreSQL) - Cloud Database

Authentication: Supabase Auth (Secure Admin Login)

Deployment: Vercel (Edge Network)

ERP System Architecture

  • Client Tier: Browsers interacting with the Next.js Frontend (Website & Exam Portal).
  • ERP Admin Tier: Next.js Server rendering secure UI and executing Admin API routes.
  • Database Tier: Supabase PostgreSQL handling admissions, exams, results, and media assets.
  • Storage Tier: Supabase Cloud Storage buckets for uploaded academy photos and videos.

Module 1 - The Public Portal

  • Cinematic Hero Section: Deep military gradients with glowing metallic typography.
  • Dynamic Content: Courses, Strengths, and Testimonials loaded dynamically from the ERP.
  • Premium Lightbox Gallery: Clickable photos and inline video players with frosted-glass overlays.
  • Responsive Design: 100% optimized for Mobile, Tablet, and Desktop.

Module 2 - Academy ERP Dashboard

  • Student Management: View, edit, and manage all student admission data in real-time.
  • Dynamic Receipts: Instantly generate printable, fully-formatted admission forms/receipts.
  • Media Controller: Upload new gallery photos, videos, and assign placements directly from the dashboard.
  • Secure Access: Role-based protected routes ensuring only authorized personnel can access academy data.

Module 3 - CBT Exam Portal

  • Exam Creation: Admins can create custom tests with multiple-choice questions via the ERP.
  • Real-Time Testing: Students experience a realistic timer-based exam environment.
  • Concurrency Handling: Advanced database logic to prevent duplicate exam starts.
  • Instant Results: Automatic evaluation and result generation upon submission.

Future Scope

  • Payment Gateway: Integration with Razorpay/PhonePe for seamless online fee collection.
  • Inventory Management: Tracking academy physical assets (uniforms, training equipment).
  • Mobile Application: A dedicated Android/iOS app for students.
  • WhatsApp/SMS Integration: Automated alerts for student attendance and exam marks to parents.

Conclusion

  • The project successfully established a highly professional digital identity AND a powerful backend ERP System for Shivrakshak Academy.
  • By digitizing admissions and exams, administrative overhead is reduced by over 80%.
  • The use of Next.js and Supabase ensures the ERP platform is highly scalable, secure, and ready for future technological expansions.
